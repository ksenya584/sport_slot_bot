# Бот для отслеживания свободных слотов

Каждые 5 минут проверяет страницы из `config.json` и пишет в Telegram, когда появляются слоты.

## Как добавить страницу
Откройте `config.json` (значок карандаша на GitHub) и добавьте блок:

    {
      "name": "Название для себя",
      "url": "https://...",
      "type": "timepad"
    }

Для страниц не с Timepad: `"type": "text"` плюс `"closed_text": "текст, который виден, пока мест нет"`.
